End‑to‑End Call Center Operations Analytics Suite (Power BI + Excel + VBA)
📌 Overview
This project is a complete operational analytics system integrating Quality Control (QC), Attendance, and Workforce Management (WFM) data into a unified Power BI solution. It includes:

A multi‑sheet Excel scoring engine

A VBA macro for automated call ID generation

A Power BI data model

4 interactive dashboards

40+ DAX measures

A full QC scoring logic pipeline

This system mirrors real‑world call center analytics used by supervisors, QA teams, and operations leaders.

🧩 Scoring Engine Overview
The scoring engine evaluates each audit using a multi‑step logic model:

Identify call type (DV or AL)

Determine applicable critical/important items

Capture missed items (N,P,R,T,V,X)

Count critical and important misses

Generate item‑level binary scores

Compute critical, important, and weighted accuracy

Determine pass/fail

Generate error summaries

This creates analytics‑ready data for Power BI.

⚙️ Macro Documentation
Macro: GenerateCallIDs  
Purpose: Automatically generates unique call IDs for each audit row.
Benefits:

Prevents duplicates

Ensures referential integrity

Supports Power BI relationships

Reduces manual entry
